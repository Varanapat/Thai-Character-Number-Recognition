# Thai Character & Number Recognition

จำแนกตัวอักษรไทยและเลขไทยที่เขียนด้วยลายมือ ด้วย **ResNet50 (ImageNet-pretrained)** บน PyTorch

ผลล่าสุด: **validation accuracy 94.93%** จาก 81 คลาส (พยัญชนะ สระ วรรณยุกต์ และเลขไทย)

> คำอธิบายโครงสร้างและที่มาของชุดข้อมูล อยู่ที่ [Dataset/README.md](../Dataset/README.md)

---

## 1. ข้อมูลที่ใช้

รวมจาก 3 แหล่งใน `Dataset/character/<code>/<D1|D2|D3>/` และ `Dataset/number/<code>/<D1|D2|D3>/`
โดยโฟลเดอร์ `<code>` คือรหัส TIS-620 ของตัวอักษร (161 = ก, 240 = ๐) แปลงกลับเป็นตัวอักษรได้ด้วย `bytes([code]).decode("tis-620")`

| แหล่ง | ที่มา | จำนวนรูป | คลาสที่ใช้ได้ | รูปต่อคลาส | ลักษณะรูป |
|---|---|---|---|---|---|
| D1 | DL - AJ | 62,519 | 70 | 5–4,857 (เฉลี่ย 893) | ขาวดำ เล็กมาก ~15×20 px |
| D2 | THI - C168 | 76,927 | 68 | 990–1,195 (เฉลี่ย 1,131) | ภาพสี ~145×140 px ขอบขาวเยอะ |
| D3 | Burapha | 23,835 | 77 | 168–975 (เฉลี่ย 310) | ขาวดำ จัตุรัส ~24–60 px |
| **รวม** | | **163,281** | **81** | 173–6,190 | |

ข้อสังเกต
- **ไม่ได้ใช้ `Dataset/Mixed`** เพราะรูปไม่ได้แยกตามตัวอักษร จึงไม่มี label
- คลาส 218–223, 238, 239 ไม่มีรูปเลย (เป็นช่วงรหัสที่ TIS-620 ไม่ได้ใช้) จึงเหลือ 81 คลาส
- D2 ไม่มีเลขไทยทั้งหมด ส่วน D1 มีบางคลาสที่มีแค่ 1–4 รูป
- จำนวนรูปต่อคลาสต่างกันได้ถึง 35 เท่า แต่ยังไม่ได้ทำ oversampling หรือถ่วงน้ำหนัก loss

## 2. การเตรียมรูป (preprocessing)

เพราะแต่ละแหล่งมีขนาดและสัดส่วนต่างกันมาก จึงทำให้เป็นมาตรฐานเดียวกันก่อน

1. แปลงเป็น grayscale
2. crop เฉพาะกรอบที่มีหมึก (พิกเซลที่เข้มกว่า 128) — ตัดขอบขาวของ D2 ออก
3. pad เป็นสี่เหลี่ยมจัตุรัสโดยเว้นขอบ 15% — คงสัดส่วนตัวอักษรไว้
4. resize เป็น 96×96 แล้วทำซ้ำเป็น 3 channel ให้เข้ากับ input ของ ResNet50
5. normalize ด้วย mean 0.5 / std 0.5

ผลลัพธ์ถูก cache ไว้ที่ `data/cache_96.npz` (~1.4 GB, ไม่ได้ commit) สร้างครั้งแรกใช้เวลาราว 5 นาที หลังจากนั้นโหลดได้ทันที

**Augmentation ตอน train** (ทำบน GPU ทีละ batch): สุ่มหมุน ±10°, shear ±8°, scale 0.85–1.1, เลื่อน ±8%
ตั้งใจให้ไม่แรงเกิน เพราะตัวอักษรไทยหลายคู่ต่างกันเพียงรายละเอียดเล็ก ๆ (ผ/ฝ, ช/ซ, ฎ/ฏ, ี/ื)

## 3. การ train

| | |
|---|---|
| โมเดล | ResNet50 pretrained (`IMAGENET1K_V2`) เปลี่ยน `fc` เป็น 81 คลาส, 23.7M params |
| แบ่งข้อมูล | train 130,624 / val 16,328 / test 16,329 (80/10/10 stratified) |
| Optimizer | AdamW, weight decay 1e-4 |
| LR schedule | OneCycleLR, max_lr 1e-3, pct_start 0.15 |
| Loss | CrossEntropy + label smoothing 0.1 |
| Batch size | 128 |
| อุปกรณ์ | Apple M5 GPU ผ่าน MPS (TensorFlow ในเครื่องรันได้แค่ CPU จึงเลือก PyTorch) |

## 4. ผลลัพธ์

train ไป 14 epoch ใช้เวลารวมประมาณ 3 ชั่วโมง (เฉลี่ย ~12 นาทีต่อ epoch) แล้วหยุดระหว่าง epoch ที่ 15

| epoch | train loss | train acc | val loss | **val acc** |
|---:|---:|---:|---:|---:|
| 1 | 1.6648 | 74.51% | 0.4672 | 90.14% |
| 2 | 1.0488 | 90.93% | 0.4179 | 92.18% |
| 4 | 0.9779 | 92.93% | 0.3786 | 92.39% |
| 6 | 0.9439 | 93.81% | 0.3275 | 93.62% |
| 8 | 0.9109 | 94.75% | 0.3103 | 94.10% |
| 10 | 0.8754 | 95.92% | 0.2956 | 94.51% |
| 12 | 0.8429 | 97.00% | 0.2958 | 94.82% |
| 13 | 0.8305 | 97.52% | 0.2903 | 94.82% |
| **14** | 0.8227 | 97.84% | 0.2891 | **94.93%** |

(ค่าทุก epoch อยู่ใน `outputs/resnet50/history.json`)

สิ่งที่อ่านได้จากตาราง
- accuracy ไต่ขึ้นเรื่อย ๆ และ val loss ยังลดลงจนถึง epoch สุดท้าย แปลว่า **ยังไม่ overfit** และน่าจะดีขึ้นได้อีกถ้า train ต่อ
- ช่วง epoch 3–5 ตัวเลขนิ่งเพราะ learning rate อยู่ที่จุดสูงสุดของ OneCycle จากนั้นดีขึ้นชัดเมื่อ LR ลดลง
- ช่องว่างระหว่าง train (97.84%) กับ val (94.93%) เริ่มกว้างขึ้นใน epoch หลัง ๆ เป็นจุดที่ควรจับตาถ้า train ยาวกว่านี้

**ยังไม่ได้วัดผลบน test set** เพราะหยุด train ก่อนจบ ขั้นตอนวัดผล test อยู่ท้ายสคริปต์ซึ่งยังไม่ได้รัน ตัวเลข 94.93% ข้างบนจึงเป็นผลบน validation set
ถ้าต้องการผลบน test set ให้รัน `train_resnet50.py` ต่อจนจบ หรือโหลด `outputs/resnet50/best.pt` มาประเมินด้วย split เดิมใน `outputs/resnet50/split.npz`

## 6. วิธีใช้งาน

ติดตั้ง dependencies

```bash
pip install -r requirements.txt
```

train แบบใช้ข้อมูลทุกแหล่ง

```bash
python train_resnet50.py --epochs 15
```

ตัวเลือกที่ใช้บ่อย: `--epochs`, `--batch-size`, `--lr`, `--img-size`, `--out`

ทายรูปใหม่ (คืนรหัสตัวอักษร 3 อันดับพร้อมความมั่นใจ)

```bash
python predict.py path/to/image.png
```

ถ้าใช้โน้ตบุ๊ก ให้เลือก kernel **"Thai HCR (.venv)"** แล้ว Run All
อยากลองให้เร็วก่อนให้ตั้ง `subset=0.05` ใน cell Config เพื่อใช้ข้อมูลแค่ 5%

## 7. ข้อจำกัดและงานที่ทำต่อได้

- ยังไม่ได้วัดผลบน test set ตามที่อธิบายในหัวข้อ 4
- ยังไม่ได้จัดการเรื่องจำนวนรูปต่อคลาสที่ไม่เท่ากัน ทำได้ด้วยการ oversample คลาสเล็กตอนสุ่ม batch หรือถ่วงน้ำหนัก loss ซึ่งไม่ต้องสร้างรูปเพิ่ม
- ยังไม่ได้ทดสอบข้ามแหล่ง เช่น train ด้วย D1 แล้วทดสอบกับ D2/D3 ซึ่งจะบอกได้ว่าโมเดลทนกับลายมือแบบที่ไม่เคยเห็นแค่ไหน
- `Dataset/Mixed` ยังไม่ได้ใช้ ถ้าแยก label ได้จะเพิ่มข้อมูลได้อีก
- โมเดลรับรูปที่มีตัวอักษรเดี่ยว 1 ตัวเท่านั้น ยังไม่รองรับการตัดตัวอักษรจากคำหรือประโยค
